# netactuate Provider

Manage NetActuate infrastructure with Terraform: cloud and dedicated compute, VPCs and their
gateways, load balancers, BGP and anycast, object and block storage, DNS, secrets, and NKE
clusters with their add-ons.

## Authentication

The provider reads an API key from the `NETACTUATE_API_KEY` environment variable, so the key
need not appear in a configuration file. Generate one in the portal under your account's API
settings.

```shell
export NETACTUATE_API_KEY="..."
```

Set it in the provider block instead when a configuration manages more than one account.

## Example Usage

```terraform
terraform {
  required_providers {
    netactuate = {
      source  = "netactuate/netactuate"
      version = "~> 0.4"
    }
  }
}

provider "netactuate" {
  # Reads NETACTUATE_API_KEY from the environment when api_key is omitted.
}
```

## Beta surface

The cloud router resources, every resource named `netactuate_router_*` along with
`netactuate_router`, are in beta. Their schema and behaviour may change in a minor release, and
some operations depend on platform work still in progress. The rest of the provider is stable.
