# netactuate_router_vrf_interface_wireguard_peer

Manages a WireGuard peer on a router VRF WireGuard interface. Each peer represents a remote endpoint (e.g. a central datacenter, an office gateway, or another PoP router) that is allowed to connect through the WireGuard tunnel.

## Example Usage

### Peer with provided public key (bring your own keypair)

```hcl
resource "netactuate_router_vrf_interface_wireguard_peer" "central_dc" {
  router_id    = netactuate_router.pop.id
  vrf_id       = netactuate_router.pop.default_vrf_id
  interface_id = netactuate_router_vrf_interface.wg.interface_id
  name         = "central-dc"
  description  = "WireGuard tunnel to central datacenter"
  remote       = "203.0.113.1:51820"
  public_key   = var.wireguard_remote_public_key

  allowed_ips {
    network = "10.0.0.0/8"
  }

  allowed_ips {
    network = "192.168.0.0/16"
  }
}
```

### Peer with API-generated keypair

```hcl
resource "netactuate_router_vrf_interface_wireguard_peer" "branch" {
  router_id    = netactuate_router.pop.id
  vrf_id       = netactuate_router.pop.default_vrf_id
  interface_id = netactuate_router_vrf_interface.wg.interface_id
  name         = "branch-office"

  allowed_ips {
    network = "172.16.0.0/12"
  }
}

# Give these outputs to the branch office to configure their WireGuard client
output "branch_wg_public_key" {
  value     = netactuate_router_vrf_interface_wireguard_peer.branch.public_key
  sensitive = true
}

output "branch_wg_private_key" {
  value     = netactuate_router_vrf_interface_wireguard_peer.branch.private_key
  sensitive = true
}
```

## Argument Reference

### Required

- `router_id` (Number) — The ID of the cloud router. Forces recreation.
- `vrf_id` (Number) — The ID of the VRF. Forces recreation.
- `interface_id` (Number) — The ID of the WireGuard interface. Forces recreation.
- `allowed_ips` (Block List, min 1) — IP networks allowed to traverse the tunnel. Forces recreation. Each block:
  - `network` (String, required) — Network in CIDR notation, e.g. `"10.0.0.0/8"`. Forces recreation.

### Optional

- `name` (String) — Name of this peer. Forces recreation.
- `description` (String) — Description of this peer. Forces recreation.
- `remote` (String) — Remote endpoint address in `"IP:port"` format (e.g. `"203.0.113.1:51820"`). Required when `public_key` is provided. Forces recreation.
- `public_key` (String, Sensitive) — Base64-encoded WireGuard public key of the remote peer. If omitted, the API generates a key pair and returns both keys. Forces recreation.
- `pre_shared_key` (String, Sensitive) — Optional pre-shared key for additional symmetric encryption. Forces recreation.

### Computed

- `wireguard_peer_id` (Number) — The peer ID assigned by the API.
- `public_key` (String, Sensitive) — The peer's public key (populated when generated by the API).
- `private_key` (String, Sensitive) — The peer's private key (only set when generated by the API; not available if you provided your own `public_key`).

## Notes

- All configuration is immutable after creation. Any change requires destroying and recreating the peer.
- When omitting `public_key`, the API generates a WireGuard keypair. The `private_key` output is only available immediately after creation — Terraform stores it in state. Rotate by recreating the resource.

## Import

```
terraform import netactuate_router_vrf_interface_wireguard_peer.central_dc <router_id>/<vrf_id>/<interface_id>/<wireguard_peer_id>
```
